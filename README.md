# 2026 학교폭력 실전 플레이북 (PWA)

2026년도 일부개정 「학교폭력 사안처리 가이드북」(교육부, 2026-02-27 게시, 216쪽)만을 기준으로 만든
**사안처리 실전 웹앱**입니다. 모든 문장·기한·조치에는 원문 쪽수 배지(`p.52-53` 등)가 붙어 있고,
쪽수를 댈 수 없는 내용은 넣지 않았습니다.

## 무엇이 들어 있나

| 탭 | 기능 |
|---|---|
| 🧭 분기 트리 | 인지·접수 → 분리(24h·7일·예외 4종·2026 신설 재분리) → 긴급조치(④·⑤·⑥) → 조사·전담기구(14일+7일) → 자체해결 4요건 인터랙티브 체크 → 심의위 1~9호·점수표 → 기재·유보·삭제 → 불복까지 클릭으로 따라가는 분기 트리. 특수 분기(성폭력·아동학대·맞신고·2호 위반·사안 아님·이주배경·졸업 직전 삭제) 바로가기 포함. |
| ⏱️ 기한 계산기 | 인지일 입력 시 24시간 분리·48시간 보고·7일 분리 종료(초일 산입·공휴일 포함)·14일·21일 자동 계산. 심의위 요청일·조치 결정일을 넣으면 보호조치 7일·가해 조치 14일·통보 14일·특별교육 3개월·행정심판 90/180일까지. 결과 표 복사. |
| 📘 생기부 계산기 | 조치 1~9호(＋긴급조치 2호) 선택 시 기재 여부·조건부 기재유보·삭제 시기·졸업 직전 심의 가능 여부. 조치결정일·졸업학년도를 넣으면 6개월 요건 판정, 확인자료 ①~⑤ 체크, 100점 배점 예시 계산. |
| 🚨 지뢰·예외 | 검증된 현장 사례 9건(🔴2·🟡5·🟢2)을 등급 필터로 대조. 2026 개정 11건 표, 폐기 11건 + 현장 오해 4건. |
| 🔍 검색·양식 | 규정·기한·지뢰·양식 통합 검색(유형 필터), 부록1 양식 23종 색인, 목차·쪽수 지도. |

- 오프라인: `sw.js`(Network-First, `?v=1`)로 앱·데이터를 캐시. 한 번 열면 비행기모드에서도 뜹니다.
- 설치: 모바일 브라우저에서 "홈 화면에 추가" → standalone 앱처럼 실행.

## 파일 구조

```
index.html                 화면 골격(4탭)
css/app.css                스타일(모바일 우선, PC 좌측 레일, 다크모드)
js/tree.js                 분기 트리 노드 데이터(모든 문장·쪽수 근거 포함)
js/app.js                  라우팅·트리 렌더·계산기·지뢰·검색
data/official_2026.json    2026 가이드북 색인(기한·규정·조치·양식·개정·폐기)
data/cases_public.json     검증 사례 9건(공개용 — 출처 식별정보 제거)
data/official_2026.md      원문 색인 마크다운(사람이 읽는 기준 문서)
data/cases_2026.json       ⚠️ 내부 원본(카페 글 번호·URL 포함) — 배포 금지
tools/build-cases-public.py  cases_2026.json → cases_public.json 살균 변환
tools/make-icons.py        PWA 아이콘 생성(192/512/maskable)
tools/verify.py            Playwright 로컬 전수 검증(146개 체크)
manifest.webmanifest       PWA 매니페스트
sw.js                      서비스워커(Network-First)
icons/                     PNG 아이콘 3종
shots/                     검증 스크린샷(모바일 390×844 / PC 1280×900)
logs/verify-report.md      최근 검증 결과 체크리스트
```

## 실행

```bash
cd work/hakpok-playbook
python3 -m http.server 8000
# http://localhost:8000/index.html
```
(`file://`로 열면 데이터 fetch와 서비스워커가 동작하지 않습니다. 반드시 http로 여세요.)

## 검증

```bash
cd work/hakpok-playbook
LD_LIBRARY_PATH=/workspace/.cache/pw-libs:$LD_LIBRARY_PATH python3 tools/verify.py
```
- 모바일 390×844에서 분기 트리 **모든 노드·모든 옵션·게이트 양쪽 분기**를 실제 클릭으로 순회
- 기한·생기부 계산값, 지뢰 필터/개정 11건/폐기 11건/오해 4건, 검색 6종 질의, 양식 23종
- 콘솔 에러 0 · 페이지 예외 0 · 실패 요청 0 · 모바일 가로 넘침 0
- 개인정보 0건: 화면 텍스트 + 모든 배포 리소스에서 학교명·성명·핸들·카페 식별자 검사
- 서비스워커 등록 후 오프라인 전환·재접속 동작 확인
- 결과는 `logs/verify-report.md`, 화면은 `shots/`

## GitHub Pages 배포 시 (아직 배포하지 않음)

공개 저장소에는 아래 **공개 파일만** 올립니다. `data/cases_2026.json`, `tools/`, `logs/`, `raw/`는 올리지 않습니다.

```
index.html  manifest.webmanifest  sw.js  css/  js/  icons/
data/official_2026.json  data/cases_public.json  data/official_2026.md
```
배포 위치가 `https://<user>.github.io/hakpok-playbook/` 처럼 하위 경로여도 되도록 모든 경로는 상대경로입니다.
`manifest.webmanifest`의 `id`는 `/hakpok-playbook/`으로 두었으니, 저장소 이름이 다르면 함께 바꿉니다.

## 데이터 갱신

- 가이드북 쪽수·조항이 바뀌면 `data/official_2026.json`과 `js/tree.js`의 문장을 같이 고칩니다(둘 다 쪽수 배지를 갖고 있음).
- 사례를 늘리면 `data/cases_2026.json`에 넣고 `python3 tools/build-cases-public.py`로 공개본을 다시 만듭니다.
- `sw.js`의 `VERSION`을 올리면 이전 캐시가 정리됩니다.

## 원칙

- **개인정보 0건**: 학교명·학생명·보호자 정보·실제 사안 내용은 앱과 데이터에 넣지 않습니다. 사례는 유형·절차 중심으로 일반화했습니다.
- **추측 금지**: 모든 수치·기한·조치는 2026 가이드북 쪽수로 확인된 것만 사용합니다. 확인되지 않은 관행은 "지원청 확인"으로 표시했습니다.
- **대체 불가 안내**: 이 앱은 실무 보조입니다. 최종 판단은 2026 가이드북 원문·교육지원청 지침·학교 규정을 따릅니다.
