# 2026 학교폭력 실전 플레이북 (PWA, v4)

2026년도 일부개정 「학교폭력 사안처리 가이드북」(교육부, 2026-02-27 게시, 216쪽)만을 기준으로 만든
**사안처리 실전 웹앱**입니다. 모든 문장·기한·조치에는 원문 쪽수 배지(`p.52-53` 등)가 붙어 있고,
쪽수를 댈 수 없는 내용은 넣지 않았습니다. 원문에 없는 처리는 "소속 교육지원청 확인"으로 표시했습니다.

## 무엇이 들어 있나

| 탭 | 기능 |
|---|---|
| 🧭 분기 트리 | 인지·접수 → 분리(24h·7일·예외 4종·재분리) → 긴급조치(④·⑤·⑥) → **조사(전담조사관 인계 흐름 / 전담기구 자체조사 분기)** → 자체해결 4요건 인터랙티브 체크 → 심의위 1~9호·점수표 → 기재·유보·삭제 → 불복까지 클릭으로 따라가는 분기 트리. 특수 분기(성폭력·아동학대·맞신고·2호 위반·사안 아님·이주배경·**사이버폭력·타교/교외/방학·자체해결 후 재요청·교권침해 경합**·졸업 직전 삭제) 바로가기 포함. **단계마다 그 단계에서 쓸 양식 칩**이 붙고, 누르면 작성 주체·제출/보관·주의사항이 뜹니다. |
| ⏱️ 기한 계산기 | 인지일·**분리 시행일** 입력 시 24시간 분리·48시간 보고·**분리기간 만료(시행일 포함 7일)**·14일·21일과 D-day를 계산. 심의위 요청일·조치 결정일을 넣으면 보호조치 7일·가해 조치 14일·통보 14일·특별교육 3개월·행정심판 90/180일까지. **토·일요일 만료일에는 경고 배지**(분리기간만 "주말 포함·연장 없음"). 결과 표 복사. |
| 📘 생기부 계산기 | 조치 1~9호(＋긴급조치 2호) 선택 시 기재 여부·조건부 기재유보·삭제 시기·졸업 직전 심의 가능 여부. 조치결정일·졸업학년도를 넣으면 6개월 요건 판정, 확인자료 ①~⑤ 체크, 100점 배점 예시 계산. |
| 🚨 지뢰·예외 | 검증된 현장 사례 **76건**(🔴27·🟡29·🟢20)을 등급·단계 필터 + 사례 내 검색으로 대조. 카드마다 **"초보 실수 → 실무 포인트" 1줄 요약**을 먼저 보여 주고 상세는 접기/펼치기(전체 펼치기·검색 시 자동 펼침). 2026 개정 11건 표, 폐기 11건 + 현장 오해 58건. **🎯 O/X 퀴즈 24문항**(정답·쪽수·검증 결론·함정 이유 즉시 해설). |
| 🗂️ 진행 체크 | 이름 없이 **익명 라벨 + 인지일**로 사안 1~3건을 `localStorage`에 저장하고, 접수대장·2호·24h 분리·48h 보고·분리 종료·14일·21일·통보·서류 단계의 기한·D-day·양식을 따라갑니다. 개인정보로 보이는 입력(전화번호·이메일·학급 표기)은 저장을 막고 안내합니다. |
| 🔍 검색·양식 | 규정·기한·지뢰·양식 통합 검색(유형 필터), 부록1 양식 23종 색인(누르면 사용 안내), 목차·쪽수 지도. |

- 오프라인: `sw.js`(Network-First, 캐시 `hakpok-playbook-v4`)로 앱·데이터를 캐시. 한 번 열면 비행기모드에서도 뜹니다.
- 자동 연결(준비): `…/hakpok-playbook/#s=<base64url>` 링크로 열면 그 안의 연결 주소를 `localStorage`(`hakpok.execUrl`)에 저장하고 주소창 해시를 정리합니다. 상단 `🔗 연동`에서 주소를 직접 저장하거나 `이 페이지 링크 복사`로 `#s=` 링크를 뽑을 수 있습니다. 지금은 서버를 쓰지 않으므로 저장만 하고, 시트 연동 기능을 붙일 때 이 주소를 씁니다.
- 설치: 모바일 브라우저에서 "홈 화면에 추가" → standalone 앱처럼 실행.

## 실행


## 데이터 갱신

- 가이드북 쪽수·조항이 바뀌면 `data/official_2026.json`과 `js/tree.js`의 문장을 같이 고칩니다(둘 다 쪽수 배지를 갖고 있음).
- 사례를 늘리면 `data/_qa_staging.jsonl`(검증 원장)에 한 줄 추가 → `python3 tools/merge_qa.py` → `data/cases_oneline.json`에 1줄 요약 추가 → `python3 tools/build-cases-public.py` 순서로 공개본을 다시 만듭니다.
- 양식 안내는 `js/stagedata.js`의 `FORMS`, 단계 연결은 `NODE_FORMS`에서 고칩니다.
- `sw.js`의 `VERSION`과 `?v=` 캐시 버스터를 함께 올리면 이전 캐시가 정리됩니다.

## 원칙

- **개인정보 0건**: 학교명·학생명·보호자 정보·실제 사안 내용은 앱과 데이터에 넣지 않습니다. 사례는 유형·절차 중심으로 일반화했습니다.
- **추측 금지**: 모든 수치·기한·조치는 2026 가이드북 쪽수로 확인된 것만 사용합니다. 확인되지 않은 관행은 "지원청 확인"으로 표시했습니다.
- **로컬 저장만**: 진행 체크는 브라우저 `localStorage`에만 저장되며 서버로 전송하지 않습니다.
- **대체 불가 안내**: 이 앱은 실무 보조입니다. 최종 판단은 2026 가이드북 원문·교육지원청 지침·학교 규정을 따릅니다.
